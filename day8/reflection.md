# Day 8 Reflection

## The Hardest Concept

The hardest concept for me was asynchronous JavaScript: fetch, Promises and async/await. At first I could not understand how code could wait for a server without freezing the page. I broke it into small steps: fetch returns a Promise, await pauses that function until the data arrives, and try/catch handles failures. Building the Project 2 API client made it click, because I could watch the loading, success and empty states update live in the browser.

## What I Would Improve

Based on the feedback on my QuickNotes design documents, I would improve how I review documentation before submitting. Some sections were missing or cut off after the diagrams. Next time I will build a checklist from the brief, tick off every requirement, and preview the Markdown on GitHub rather than trusting the editor alone. This taught me that documentation needs the same care as code.

After that I will study The System Design Primer to become more confident designing systems for large traffic spikes, like the TicketHub sale.
